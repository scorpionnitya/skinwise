1. Project overview

Working niche: Affordable, beginner-friendly skincare education for college students in India.

Proposed site name: Skinwise Student Skincare. A domain name has not been selected or checked for availability; choose and register one only after checking it at a registrar.

Project goal: Publish a small, useful WordPress resource that answers beginner skincare questions with simple explanations, realistic budget framing, clear citations, and no unsupported promises about treating or curing skin conditions.

Niche justification (147 words)

Affordable beginner skincare for Indian college students is an SEO niche with a clear audience and recurring educational search needs. An exploratory India-oriented result sample surfaced beginner and minimal-routine guides from Smytten and CodeSkin India plus skin-care editorial content on Nykaa's Beauty Book. The pages emphasize practical formats such as AM/PM routines, product order, and common beginner mistakes. Brand and retail links were visible on the pages inspected. India's dermatologist association IADVL also publishes basic skincare guidance, giving the project an authoritative reference source. This supports a testable opportunity for an independent, non-commercial student guide focused on simple routines, realistic budgets, campus schedules, and clearly cited advice. These observations are qualitative; the exploratory sample does not establish Google rankings, monthly search volume, or demand size. The next research step is to capture India/English keyword metrics and a Google India SERP sample before claiming market size.

Search-intent pattern

  • Informational: understand a basic routine, product order, skin-care terminology, and beginner mistakes.
  • Commercial investigation: compare affordable product categories or ingredients before deciding what to buy. Keep claims neutral and disclose any future affiliate relationship.
  • Transactional: buying a named product. The proposed project is educational and does not need to target product purchase pages in Milestone I.
  • Navigational: searches for an existing brand or publication. Do not target competitor brand names as primary keywords.

SEO problem statement

New skincare readers encounter overlapping routine advice and product-led articles. Skinwise will test whether a clearly scoped, student-oriented guide can meet beginner informational intent more directly by explaining the minimum useful steps, linking medical questions to qualified sources, using transparent and date-stamped cost examples, and organizing related topics without making multiple pages compete for the same query.

7. Domain, DNS, and Cloudflare checklist

  1. Choose a short brand-led domain, check availability at a registrar, and register it using your account. A candidate is not a registered domain until checkout completes; no availability is claimed here.
  2. Create a Cloudflare account and add the domain. At the registrar, replace nameservers with the exact two Cloudflare assigns. Wait for the dashboard to show the zone as active.
  3. In Cloudflare DNS, create an A record for @ pointing to the VPS public IPv4 and a CNAME for www pointing to the chosen canonical hostname (or @). Verify target and proxy status before testing. Do not publish a guessed IP.
  4. In the VPS, configure the same hostname in the Nginx server block and install a valid origin certificate (Let's Encrypt/Certbot or Cloudflare Origin CA). Set Cloudflare SSL/TLS to Full (strict) only after the origin certificate works.
  5. Choose one canonical host, redirect the other to it, and check for redirect loops. Keep WordPress admin, login, previews, and logged-in/personalized traffic out of broad HTML caching. Use WordPress-aware caching rules/plugin for public pages. Enable Cloudflare minification only after a baseline test, then retest the site so scripts or styles are not broken.
  6. For evidence, capture Cloudflare nameserver/active status, DNS records (hide unrelated account details), Full (strict) setting, HTTPS lock and redirect, and a dated DNS propagation result.

8. VPS and WordPress implementation plan

These are steps to perform in your VPS account; they have not been run by this project. Use an Ubuntu LTS image, a provider firewall, SSH keys, and the provider’s current WordPress/LEMP guide. Keep passwords, private keys, and database credentials out of this report, screenshots, and chat.

  1. Create a small Ubuntu LTS VPS and note its public IPv4. Restrict SSH to your address where possible; allow SSH, HTTP, and HTTPS in the provider firewall.
  2. Connect using your own SSH key. Update the system, install Nginx, MySQL/MariaDB, PHP-FPM with the WordPress extensions, and a firewall. Follow the VPS vendor’s current instructions for PHP version and Nginx site configuration.
  3. Secure the database, create a dedicated WordPress database and non-root database user, and use a unique long password. Download WordPress from WordPress.org or use WP-CLI, configure the document root and Nginx server block, then finish installation over HTTPS.
  4. Install a maintained responsive theme, create a unique administrator account, disable unused themes/plugins, set readable permalinks, enable automatic security updates/backups, and verify that public pages load without authentication.
  5. Issue and renew a valid TLS certificate. Configure Cloudflare Full (strict), verify both root and www behavior, then add caching without breaking WordPress admin or dynamic sessions.
  6. For Milestone I, demonstrate a functional homepage, About page and one draft/published article. The SEO plugin/schema/analytics details are primarily Milestone II requirements.

Likely viva questions

  • Why this niche? It serves a clearly described beginner audience with informational and commercial-investigation queries; the niche was chosen as a testable project, not because search demand or ranking was guaranteed.
  • What is intent? The need behind a query. The core article targets informational intent; product selection questions may be commercial investigation.
  • Is Google Ads Competition the same as keyword difficulty? No. Ads competition estimates advertiser competition. Organic KD is an SEO tool's estimate of ranking difficulty.
  • How do you prevent cannibalization? Assign one primary query and intent to each page; consolidate overlapping drafts and use internal links to make the hierarchy clear.
  • Why Cloudflare Full (strict)? It encrypts traffic from visitor to Cloudflare and from Cloudflare to the origin while requiring a valid origin certificate.
  • Can you guarantee a ranking? No. Search systems and competition change; measure crawl/index status and query performance over time.
